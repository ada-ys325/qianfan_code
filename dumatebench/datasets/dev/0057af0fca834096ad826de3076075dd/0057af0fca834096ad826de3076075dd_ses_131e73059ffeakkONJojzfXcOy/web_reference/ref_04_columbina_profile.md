## 与任务相关的关键事实摘要

- 哥伦比娅曾为愚人众执行官第三席，代号“The Damselette / 少女”。
- 性格资料显示她因长期隔绝而社交能力较弱，给人神秘、奇异、危险但天真无辜的印象；说话较少过滤，带有天然、单纯、轻微毒舌和不按常理反应的感觉。
- 她与桑多涅有同僚关系，资料中特别提到她会欣赏部分同僚的陪伴，尤其是桑多涅。
- 外貌关键词：中等少女体型，苍白皮肤，黑色长发带深粉/洋红挑染，两侧编发，白色缎带交叉装饰；多数时候闭眼，睁眼时为浅粉近珠光色眼睛。
- 该资料的“天然、无辜、说话不过滤、神秘而危险”描述可与用户要求的搜索关键词“天然呆的哥伦比娅”合并使用，但应在 prompt 中表现为轻松可爱的天然呆，不表现危险或压迫感。

## 为什么对任务有用

任务特别要求补全哥伦比娅“天然呆”性格，并要求她和桑多涅一起玩。该资料可用于把哥伦比娅设定成闭眼、天真、神秘、轻飘飘的少女，同时在构图中让她与桑多涅保持互动。
