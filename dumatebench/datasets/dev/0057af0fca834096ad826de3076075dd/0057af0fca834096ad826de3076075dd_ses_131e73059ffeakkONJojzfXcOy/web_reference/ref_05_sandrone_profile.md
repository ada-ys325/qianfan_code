## 与任务相关的关键事实摘要

- 桑多涅是愚人众执行官第七席，代号“木偶 / Marionette”。
- 资料页的外貌描述确认她是浅肤色、中等身高的年轻女性形象，蓝灰色眼睛，米色头发束成编发发髻，两侧有长发束修饰脸颊。
- 服装关键词：白色长裙、红色褶边、黑色束身衣、红宝石色装饰、白手套、白袜和黑色鞋；头戴白黑金配色、有红色系带和黑色蝴蝶结的帽饰，背后带人偶发条钥匙。
- 设定关键词：愚人众执行官、木偶、机关/自动机、机械工程、机械随从。
- 性格可概括为理性、傲慢、讲求演算与机械逻辑，但在玩家社区对“少偶”关系的解读中常带有傲娇和口是心非的一面。

## 为什么对任务有用

任务明确要求确认桑多涅作为愚人众执行官的外貌设定。该来源可支撑“第七席、木偶、女性人偶、机械工程/机械随从”等关键 prompt 要素。
