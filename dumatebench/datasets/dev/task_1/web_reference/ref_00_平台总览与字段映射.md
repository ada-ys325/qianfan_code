# 中外合作办学监管工作信息平台 —— 数据源总览与字段映射指南

- **标题**: 教育部中外合作办学监管工作信息平台（审批机构 / 项目名单与详情）
- **平台首页 URL**: https://www.crs.jsj.edu.cn/
- **名单页 URL（示例）**: https://www.crs.jsj.edu.cn/aproval/index  （按省份/类型列出机构与项目）
- **详情页 URL 规律**: https://www.crs.jsj.edu.cn/aproval/detail/{id}
- **主管单位**: 中华人民共和国教育部
- **访问日期**: 2026-07-23
- **数据适用时间**: 平台为在办中外合作办学机构/项目的现行审批公示，实时更新，采集时为最新状态。

## 平台性质与可信度
- 这是教育部官方运营的中外合作办学审批信息公示平台，是本任务所有项目详情的**唯一权威原始数据源**，可核验、可复现。
- `projects.json` 中每条记录的 `url` 均指向本平台的 `aproval/detail/{id}` 详情页，共 1539 条（合作办学项目 1174 条、合作办学机构 365 条）。

## 访问技术说明（供 crawler.py 参考）
- 站点前置 SecEdge 安全校验：首次请求会 302 跳转到 `/GE/CC/VALIDATOR?...`，需**携带 cookie 跟随重定向**（curl `-L -c/-b cookiejar`）后才能拿到 200 的详情页 HTML。
- 详情页为**服务端渲染的静态 HTML 表格**（非 JS 单页应用），可直接用正则/BeautifulSoup 解析 `<table>` 中的 `<td>` 标签对。
- 建议 UA 设为常规浏览器，请求间隔 ~1s，避免触发风控。
- 未发现公开 JSON API（试探 `/api/...` 返回 404），应直接解析详情页 HTML。

## 页面字段 → 任务表头列 映射（关键）
中外合作办学分“**机构**”和“**项目**”两类，字段名不同，需分别映射到统一表头：

| 任务表头列 | 「合作办学机构」页面字段 | 「合作办学项目」页面字段 |
|---|---|---|
| 标题 | 项目 title（来自 projects.json） | 同 |
| 标题链接 | 项目 url（来自 projects.json） | 同 |
| 项目名称 | 机构名称 | 项目名称 |
| 办学地址 | 机构住所 | 办学地址 |
| 中外合作办学者1 | 中外合作办学者·中方 | 中方 |
| 中外合作办学者2 | 中外合作办学者·外方 | 外方 |
| 办学层次和类别 | 办学层次和类别 | 办学层次和类别 |
| 每期招生人数 | 办学规模 | 办学规模 / 招生说明 |
| 招生方式 | 招生方式 | 招生方式 |
| 开设专业或课程 | 开设专业或课程 | 开设专业或课程 |
| 颁发证书1 | 颁发证书·中方 | 颁发证书·中方 |
| 颁发证书2 | 颁发证书·外方 | 颁发证书·外方 |
| 审批机关 | 审批机关 | 审批机关 |
| 批准书编号 | **许可证编号** | **批准书编号** |

> 注意：机构类页面没有“批准书编号”，对应字段是“**许可证编号**”（如 `MOE11FRA02DNR20060008N`）；项目类页面才叫“批准书编号”（如 `MOE11AU2A20040440O`）。爬虫需对两种字段名做兼容。

## 为什么对任务有用
- 本文件汇总了数据源结构、访问方式（SecEdge cookie 跳转）和两类页面的字段映射规则，是编写 `crawler.py` 与生成 Excel 表头（14 列）的直接依据，避免因机构/项目字段名差异导致列错位或缺列。
